A brick breaker game built in C++ using SFML 3.0.2 for CS1002 Programming Fundamentals (Fall 2026).

## Controls

- Move Paddle Left: Left Arrow or A
- Move Paddle Right: Right Arrow or D
- Launch Ball: Space
- Menu Navigation: Up Arrow / Down Arrow and Enter
- Save Game & Return to Menu: Esc

## How to Run

1. Clone the repository from GitHub using GitHub Desktop or Git.
2. Open the Visual Studio project inside the cloned repository folder.
3. Set the solution platform to x64 and link SFML 3.0.2 include and library directories in project properties.
4. Make sure level.txt is present in the working directory so the level loads properly.
5. Build and run the project in Visual Studio.
